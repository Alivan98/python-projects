# Mobile Sensor Data Analysis using Linear Regression

This repository contains the implementation and statistical analysis for the 1st assignment of the **"Data Analysis"** course. The project explores the relationships between a smartphone's total acceleration and various environmental and inertial sensor measurements using linear and multiple regression frameworks.

## Project Overview

The core objective is to determine whether the measurements recorded by a smartphone's internal sensors are statistically significant predictors of the device's overall acceleration. The analysis transitions from simple baseline models to optimized multi-variable structures.

### Key Methodologies
* **Simple Linear Regression (SLR)**: Establishes baseline linear relationships between individual sensor outputs and total acceleration.
* **Multiple Linear Regression (MLR)**: Evaluates the combined predictive power of multiple independent sensor channels simultaneously.
* **Forward Selection**: Employs an automated step-by-step feature selection algorithm to identify the optimal subset of predictors and construct the best performing model.
* **Non-Linearity Diagnostics**: Investigates statistical indicators and residual patterns to detect non-linear behaviors between the response variance and independent sensor metrics.

---

## Experiment & Data Collection

The underlying dataset was generated through a real-world physical experiment using a dedicated logging application:
* **Data Source**: Recorded via the Android application **Sensor Logger** (available on the Google Play Store).
* **Environment**: A 10-minute walk conducted at 21:00 in the eastern city center of Thessaloniki, Greece. 
* **Dynamic Conditions**: The route covered varying ambient lighting conditions (brightly lit vs. darker areas) and diverse movement patterns (varying walking paces, accelerations, and decelerations).

### Recorded Features (Independent Variables)
All sensor data points were captured uniformly at a sampling frequency of **1 measurement per second (1 Hz)**:

1. **Accelerometer**: Logs linear acceleration across the 3 spatial axes ($x, y, z$).
2. **Gyroscope**: Records the device's rotation rate/angular velocity across the 3 spatial axes ($x, y, z$).
3. **Magnetometer**: Measures the Earth's local magnetic field strength across the 3 spatial axes ($x, y, z$).
4. **Light Sensor**: Captures ambient light intensity levels (lux).

> **Scope Note**: For brevity and structural focus, the evaluated regression models in this specific implementation isolate and analyze data corresponding strictly to the **x-axis**. An identical comparative analysis can be extended symmetrically to the $y$ and $z$ components.

## Machine Learning & Statistical Architecture

### Target Variable (Dependent Feature)
* **Total Acceleration**: The compound structural acceleration profile of the mobile device during the walking itinerary.

### Analytical Pipeline
1. **Feature Extraction**: Parses raw time-series text/CSV logs generated by the Sensor Logger app.
2. **Statistical Modeling**: Fits ordinary least squares (OLS) regression curves to map sensor interdependencies.
3. **Forward Stepwise Selection**: Evaluates model expansion by iteratively adding features that yield the most statistically significant improvement (based on p-values or AIC/BIC criteria).
4. **Residual Analysis**: Evaluates homoscedasticity and linearity assumptions to diagnose structural model limitations.

## Getting Started

### Prerequisites
Ensure you have Python 3.8+ along with the core data science stack installed:
```bash
pip install pandas numpy matplotlib seaborn statsmodels scikit-learn
```

### Usage
1. Export your logged sensor data into your local project workspace.
2. Execute the primary regression notebook or script to view statistical summaries:
```bash
python sensor_regression_analysis.py
```

## Analytical Outputs
The code generates standard statistical summaries and diagnostic charts:
* **Regression Coefficients Table**: Detailed outputs containing $R^2$ metrics, F-statistics, and individual feature p-values to verify statistical significance.
* **Residual Plots**: Diagnostic graphs utilized to inspect structural fitness and identify potential non-linear sensor relationships.
